# JSX / Code Style Guidelines

1. **Nested Elements**:
   If an element contains child content or nested elements, start the content on the next line:
   ```jsx
   <element>
     ...
   </element>
   ```

2. **Attribute Formatting**:
   If an element has more than 3 attributes (> 3 attributes), break each attribute onto its own line and format as:
   ```jsx
   <element
     attr-1="val"
     attr-2="val"
     attr-3="val"
     attr-4="val"
   >
     ...
   </element>
   ```
